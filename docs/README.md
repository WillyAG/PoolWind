# Documentation

License: see [LICENSE.md](../LICENSE.md).

Read them in this order:

1. **[Build guide](BUILD_GUIDE.md):** the three checks to make before buying
   anything, the interface board, wiring the remote, the Pace Display port,
   the camera and the poolside station. The parts are in the
   [parts list](../hardware/PARTS_LIST.md).
2. **[Setup and calibration](SETUP_GUIDE.md):** installing the software,
   setting the swim area, the calibration (voltage scan, Pace table, safety
   limits), the number of zones, the settings files, built-in settings and
   desk testing.
3. **[User manual](USER_MANUAL.md):** the screen and buttons, Hold mode,
   Suspend and Resume, Pace correction, the swim plot and video review,
   per-swimmer USB sticks and Swimmer limits.

The pictures used in these documents are in `images/`.
